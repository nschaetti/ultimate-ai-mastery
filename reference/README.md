# Livre de référence

Deux index seront alimentés à mesure que les leçons sont écrites : les **concepts** (broadcasting, gradient, attention, score, dynamique latente…) et les **API** (symbole + version → fiche et leçon). Ils ne sont pas encore remplis.

Une fiche peut être relue indépendamment du parcours et doit permettre de reconstruire son idée centrale en quelques minutes. Elle contient une intuition, les conventions et équations indispensables, un exemple minimal, un piège et une question de rappel actif. Utiliser le [gabarit](../templates/reference.md).

Pour l'instant, retrouver un sujet via le [sommaire](../docs/CURRICULUM.md) et une famille d'API via la [matrice des domaines](../coverage/DOMAINS.md). Lorsqu'une fiche existe, la relier dans les deux sens à la leçon correspondante. Ne pas créer des centaines de fiches vides donnant l'impression d'un livre terminé.
