# Notebooks du cursus

Les leçons seront rangées par bloc et sous-chapitre, par exemple `numpy/01-ndarray/lesson.ipynb` et `numpy/01-ndarray/solution.ipynb`. Chaque dossier pourra inclure des figures légères et un README local si nécessaire.

Cette version ne contient pas encore de leçon. Les [gabarits](../templates/README.md) fixent la forme à suivre. Le [sommaire détaillé](../docs/CURRICULUM.md) décrit les unités prévues et leur objectif vérifiable.
