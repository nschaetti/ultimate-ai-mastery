# Gabarits

`lesson.ipynb` et `solution.ipynb` sont des structures rédactionnelles, pas des cours ni des corrigés déjà écrits. Copier les deux dans le même dossier de leçon, remplacer les marqueurs et attribuer des identifiants d'exercices stables.

`reference.md` est la fiche de rappel associée. Le [contrat pédagogique](../docs/PEDAGOGY.md) définit les critères de complétion.
